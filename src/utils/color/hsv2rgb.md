# hsv2rgb

把 `hsv` 颜色转换为 `rgb` 格式。

## 基础用法

```ts
hsv2rgb('hsv(0, 100, 100)') // 'rgb(255, 0, 0)'
hsv2rgb('hsv(120, 100, 100)') // 'rgb(0, 255, 0)'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
hsv|`hsv(...)` 颜色字符串|<code>string</code>|-|是

## 注意事项

- H 按 0 - 360、S 与 V 按 0 - 100 解析。
- 结果做了 `Math.round`，返回值可直接用于 CSS。
