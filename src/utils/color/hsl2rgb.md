# hsl2rgb

把 `hsl` 颜色转换为 `rgb` 格式。

## 基础用法

```ts
hsl2rgb('hsl(0, 100%, 50%)') // 'rgb(255, 0, 0)'
hsl2rgb('hsl(210, 100%, 50%)') // 'rgb(0, 127, 255)'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
hsl|`hsl(...)` 颜色字符串|<code>string</code>|-|是

## 注意事项

- H 按 0 - 360、S 与 L 按 0 - 100 解析，百分号只是被当成普通字符跳过。
- 结果是 `Math.round` 后的整数，但受浮点影响可能比手算少 1（如 `hsl(210, 100%, 50%)` 得到 `rgb(0, 127, 255)` 而不是 `128`），做颜色比对时不要用严格相等。
