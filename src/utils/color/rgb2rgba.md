# rgb2rgba

给 `rgb` / `rgba` 颜色字符串换上指定的透明度。

## 基础用法

```ts
rgb2rgba('rgb(255, 0, 0)', 0.5) // 'rgba(255, 0, 0, 0.5)'
rgb2rgba('rgba(255, 0, 0, 1)', 0.3) // 'rgba(255, 0, 0,0.3)'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
bg|`rgb(...)` 或 `rgba(...)` 字符串|<code>string</code>|-|是
op|目标透明度，未传时原样返回入参|<code>number</code>|-|否

## 注意事项

- `op` 是**按真假判断**的，`op` 为 `undefined`、`0`、`NaN` 时函数什么都不做，直接返回原字符串。也就是说**没法用它把颜色调成全透明**。
- 内部用 `split(',')` 拼字符串，输出的逗号间距取决于输入：从 `rgba(...)` 替换来的结果形如 `rgba(255, 0, 0,0.3)`（逗号后没空格），功能上不影响 CSS 解析。
- 入参既不含 `rgb` 也不含 `rgba` 时没有返回值（`undefined`），调用方最好先确认格式。
