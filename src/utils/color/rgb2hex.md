# rgb2hex

把 `rgb` / `rgba` 颜色字符串转换为十六进制。

## 基础用法

```ts
rgb2hex('rgb(255, 0, 0)') // '#ff0000'
rgb2hex('rgb(0, 0, 0)') // '#000000'
```

`rgba` 会得到 8 位带透明度通道的写法，透明度按 **0 - 100 的整数百分比**传：

```ts
rgb2hex('rgba(255, 255, 255, 50)') // '#ffffff80'，50% 不透明度
rgb2hex('rgba(255, 255, 255, 25)') // '#ffffff40'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
rgb|`rgb(...)` 或 `rgba(...)` 字符串|<code>string</code>|-|是

## 注意事项

- 输入按「字符串里出现的第 1、2、3 个数字」当作 R、G、B 解析，所以位数不够或格式异常时不会报错，只会产出奇怪的结果。
- **透明度必须传 0 - 100 的整数**。内部按 `alpha * 2.56` 换算成两位十六进制，所以：
  - `rgba(255, 255, 255, 50)` → `'#ffffff80'`（50% 对应标准写法 `80`）；
  - `rgba(255, 255, 255, 0.5)` → `'#ffffff1.47ae147ae147b'`，**这不是合法颜色**。CSS 习惯的 `0.5` 写法在这里不能用，要写成 `50`。
  - `rgba(255, 255, 255, 100)` → `'#ffffff100'`，已是 3 位而非 2 位。需要全不透明的 8 位写法时请自己拼 `'#ffffff' + 'ff'`。
- 传入 5 个数字时（如小数被拆开的情况），会取末位数字乘以 10 作为透明度。
