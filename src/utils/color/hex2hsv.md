# hex2hsv

把十六进制颜色转换为 `hsv` 格式，内部先转 `rgb` 再转 `hsv`。

## 基础用法

```ts
hex2hsv('#ff0000') // 'hsv(0, 100, 100)'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
hex|十六进制颜色，6 位|<code>string</code>|-|是

## 注意事项

- 等价于 `rgb2hsv(hex2rgb(hex))`，所以只接受 6 位写法。
- 因为 `rgb2hsv` 不做取整，结果的小数位数可能很长，用于展示时要自己收一下。
