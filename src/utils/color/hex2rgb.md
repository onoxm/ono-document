# hex2rgb

把十六进制颜色转换为 `rgb` 或 `rgba` 字符串。

## 基础用法

```ts
hex2rgb('#ffffff') // 'rgb(255, 255, 255)'
hex2rgb('#ff0000') // 'rgb(255, 0, 0)'
```

8 位十六进制（末两位是透明度）会返回 `rgba`：

```ts
hex2rgb('#ffffff80') // 'rgba(255, 255, 255, 0.5)'
hex2rgb('#ffffff00') // 'rgba(255, 255, 255, 0)'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
hex|十六进制颜色，6 位或 8 位|<code>string</code>|-|是

## 注意事项

- 只按**长度**区分：6 位走 `rgb`，8 位走 `rgba`；3 位简写（`#fff`）不会被展开，会解析出错误结果，先过一遍 `hex3To6`。
- 透明度是用 `parseInt(末两位, 16) / 256` 算的，**除数是 256 而不是 255**，所以全不透明的 `ff` 得到的是 `0.99609375` 而不是 `1`。做透明度判断时别用 `=== 1`。
