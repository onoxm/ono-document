# grayColor

按 Rec. 709 标准计算 R、G、B 三个通道对应的灰度值。

## 基础用法

```ts
grayColor(255, 255, 255) // 254.99999999999997
grayColor(255, 0, 0) // 54.213
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
r|红色通道值（0 - 255）|<code>number</code>|-|是
g|绿色通道值（0 - 255）|<code>number</code>|-|是
b|蓝色通道值（0 - 255）|<code>number</code>|-|是

返回值|<code>number</code>（灰度值，可能带小数）
:- | :-

## 注意事项

- 权重是 `0.2126 / 0.7152 / 0.0722`，绿色对亮度的贡献最大。
- 返回的是**浮点数**，且受浮点误差影响：纯白得到的是 `254.99999999999997` 而不是 `255`。要当颜色值用记得先 `Math.round`。
