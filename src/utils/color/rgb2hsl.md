# rgb2hsl

把 `rgb` 颜色转换为 `hsl` 格式。

## 基础用法

```ts
rgb2hsl('rgb(255, 0, 0)') // 'hsl(0, 100%, 50%)'
rgb2hsl('rgb(255, 255, 255)') // 'hsl(0, 0%, 100%)'
rgb2hsl('rgb(0, 128, 255)') // 'hsl(210, 100%, 50%)'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
rgb|`rgb(...)` 颜色字符串|<code>string</code>|-|是

## 注意事项

- H、S、L 三个分量都会 `Math.round`，返回的是整数形式，可以直接嵌进 CSS。
- 灰色（R = G = B）的 H、S 都按 `0` 处理。
- 只取字符串里的数字，`rgba(...)` 的透明度部分会被忽略，不会反映到结果里。
