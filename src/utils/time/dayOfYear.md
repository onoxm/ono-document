# dayOfYear

计算给定日期是当年的第几天。

## 基础用法

```ts
dayOfYear(new Date(2026, 8, 24)) // 266
dayOfYear(new Date(2024, 11, 31)) // 365
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
date|待计算的日期对象|<code>Date</code>|-|是

返回值|<code>number</code>
:- | :-

## 注意事项

- ⚠️ **返回值的起算点比直觉少 1**：1 月 1 日返回的是 **`0`**，不是 `1`。源码注释里写的「1 起算」与实际不符。
  ```ts
  dayOfYear(new Date(2026, 0, 1)) // 0
  ```
  要展示成「第 N 天」的话记得自己 `+ 1`。
- 计算方式是与当年 1 月 1 日 0 点的时间差除以一天再向上取整，所以传入带时分秒的日期会得到「已过天数 + 1」。
- 年底平年返回 364、闰年返回 365（同样比直觉少 1）。
- 用的是**本地时区**的日期，跨时区调用同一时刻可能得到不同的天数。
