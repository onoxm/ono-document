# formatSecond

把秒数格式化成时分秒字符串。

## 基础用法

```ts
formatSecond(5) // '00:05.00'
formatSecond(65) // '01:05.0'
formatSecond(125) // '02:05'
formatSecond(3725) // '01:02:05'
```

不需要小数后缀时，强制指定格式：

```ts
formatSecond(3725, 'hh:mm:ss') // '01:02:05'
formatSecond(65, 'hh:mm:ss') // '00:01:05'，哪怕不足 1 小时也带上小时位
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
second|秒数|<code>number</code>|-|是
format|格式，仅支持 <code>'hh:mm:ss'</code>|<code>'hh:mm:ss'</code>|-|否

## 注意事项

- 默认格式下**小时为 0 时会隐藏小时段**，只显示 `MM:SS`；同时按秒数大小自动追加后缀：
  - 秒数 < 10 → 追加 `.00`
  - 秒数 < 100 → 追加 `.0`
  - 否则不追加
  这些后缀看起来像毫秒，但**只是补位的字符串**，传入 5 秒得到的是 `'00:05.00'` 而不是 5.00 秒的精确表示。
- 秒数是**向下取整**的（内部用 `Math.floor`），`formatSecond(5.9)` 会按 5 秒处理。
- 传 `'hh:mm:ss'` 时**不加后缀**，且强制显示小时位。
- 超过 24 小时不会进位到天，小时数会一直累加（`formatSecond(90000)` 得到 `'25:00:00'`）。要显示天数用 `second2Day`。
- 传负数会得到 `NaN` 或异常结果，不支持倒计时场景。
