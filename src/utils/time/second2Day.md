# second2Day

把秒数格式化成带天数的时长字符串。

## 基础用法

```ts
second2Day(90061, 'DD天hh时mm分ss秒') // '1天01时01分01秒'
second2Day(3725, 'DD天hh时mm分ss秒') // '0天01时02分05秒'
second2Day(59, 'DD天hh时mm分ss秒') // '0天00时00分59秒'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
seconds|秒数|<code>number</code>|-|是
format|格式字符串，支持 DD / hh / mm / ss|<code>string</code>|-|是

### 支持的占位符

占位符|含义|是否补零
:- | :- | :-
<code>DD</code>|天数|否
<code>hh</code>|小时|补零至 2 位
<code>mm</code>|分钟|补零至 2 位
<code>ss</code>|秒|补零至 2 位

## 注意事项

- `format` 是**必填**的（没有默认值），不传会得到 `undefined`。
- 天数是**向下取整**的整数，余额继续拆成时分秒；天数为 0 时同样会输出 `'0天'`，不会自动省略这一段。
- 小时位超过 24 不会继续进位到天（拆分逻辑先把整天取走，所以最多到 23）。
- 占位符同样是逐个 `replace` 第一个匹配，重复出现只替换首个。
- 秒数含小数时秒位会保留小数（内部对秒用的是 `%` 而不是取整）：`second2Day(1.5, 'ss')` 得到 `'1.5'`。
