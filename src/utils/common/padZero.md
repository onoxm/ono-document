# padZero

给数字左侧补零，凑到指定长度。

## 基础用法

```ts
padZero(5) // '05'，默认补齐到 2 位
padZero(5, 3) // '005'
padZero(0) // '00'
padZero(12) // '12'，已经够长就原样返回
```

常用于拼日期 / 时间：

```ts
const date = `${year}-${padZero(month)}-${padZero(day)}` // '2026-09-04'
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
number|需要补零的数字|<code>number</code>|-|是
len|目标长度|<code>number</code>|<code>2</code>|否

## 注意事项

- 判定条件是 `number < 10 ** len`：数字**位数**不超时才补零，已经够长就原样返回字符串，不会截断。
- 返回的是 **字符串**，不是数字，直接参与算术运算会变成字符串拼接。
- 负数与小数没有特殊处理：`padZero(-5)` 得到 `'-05'`（负号也算一位），`padZero(1.5, 3)` 得到 `'1.5'`。
