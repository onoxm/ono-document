# pureNumber

去掉字符串里的非数字字符，再解析成浮点数。

## 基础用法

```ts
pureNumber('abc123.45xyz') // 123.45
pureNumber('￥1,234.5') // 1234.5
pureNumber('a1.2.3') // 1.2
```

典型用途：把带单位、带货币符号的展示文本还原成可计算的值。

```ts
pureNumber('共计 1,280 元') // 1280
```

## 注意事项

- 保留的是 `0-9` 和 `.`，**负号会被丢掉**：`pureNumber('-10')` 得到 `10`，需要符号的话请自己在外面判断。
- 多个小数点会按 `parseFloat` 的规则截断：`'a1.2.3'` 得到 `1.2`。
- 串里没有任何数字时 `parseFloat` 返回 `NaN`，调用方需要自己判空。
- 与 `getAllNumbers` 的区别：这个返回**单个数字**，`getAllNumbers` 返回**所有数字组成的字符串数组**。
