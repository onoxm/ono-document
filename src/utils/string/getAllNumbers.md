# getAllNumbers

从字符串里提取所有数字（含小数）。

## 基础用法

```ts
getAllNumbers('rgba(255, 255, 255, 0.5)') // ['255', '255', '255', '0.5']
getAllNumbers('价格 128 元，折扣 7.5 折') // ['128', '7.5']
getAllNumbers('no digits') // []
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
str|原始字符串|<code>string</code>|-|是

返回值|<code>string[]</code>
:- | :-

## 注意事项

- 返回的是**字符串数组**，参与计算前需要自己 `Number(...)` 转换。
- 匹配规则是 `/(\d+\.?\d*)/g`：`.` 后必须紧跟数字才会被一起取出，所以 `'1.'` 只会得到 `'1'`，而 `'.5'` 会得到 `'5'`（小数点被当成普通字符跳过）。
- 负号不会被保留：`'-10'` 得到 `'10'`。它只负责「把数字抠出来」，不负责判断正负。
- 无匹配时返回空数组，不会返回 `null`。
