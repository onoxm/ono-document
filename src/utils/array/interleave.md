# interleave

在数组的每两个元素之间插入一个分隔元素。

## 基础用法

```ts
interleave(['a', 'b', 'c'], '-') // ['a', '-', 'b', '-', 'c']
interleave([1, 2, 3], 0) // [1, 0, 2, 0, 3]
interleave([1], 0) // [1]，只有一个元素时不插入
interleave([], 0) // []
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
arr|原始数组|<code>T[]</code>|-|是
separator|要插入的分隔元素|<code>T</code>|-|是

## 注意事项

- 返回的是**新数组**，不会修改入参。
- 分隔符是「元素」而不是字符串，可以是任意类型（对象、`null`、JSX 等），类型上要求与数组元素一致：`T[]` 配 `T`。
- 元素数量为 0 或 1 时原样返回（长度不变），调用方不需要单独判空。
- 想拼接成字符串用数组原生的 `join` 更直接；这个函数适合「在列表项之间插入一个真实节点」的场景。
