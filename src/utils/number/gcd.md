# gcd

用欧几里得算法计算两个数的最大公约数。

## 基础用法

```ts
const a = 10
const b = 20
const c = 5

gcd(a, b) // 10
gcd(b, c) // 5
```

## API

参数|说明|类型|默认值|是否必填
:- | :- | :- | :- | :-
num1|第一个数|<code>number</code>|-|是
num2|第二个数|<code>number</code>|-|是

## 注意事项

- 内部先取绝对值，传负数也能得到正确结果：`gcd(-10, 20)` 返回 `10`。
- 返回值恒为非负整数；`gcd(0, 0)` 返回 `0`。
